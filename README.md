# Boligportal Marokko

En boligportal for det marokkanske marked. Se [SPEC.md](SPEC.md) for hele planen.

Bygget med Next.js (App Router), TypeScript og Tailwind CSS.

## Kør projektet på din egen computer

```bash
npm install     # henter de pakker, projektet bruger
npm run dev     # starter siden på http://localhost:3000
```

## Andre kommandoer

```bash
npm run build   # bygger den færdige version (det samme som Vercel gør)
npm run lint    # tjekker koden for typiske fejl
```
